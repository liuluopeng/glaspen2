# S8 真机验收清单(macOS,应用层 ObjC 清零后)

> 目的:S0–S7 的编译/单测/契约闸门已全绿,但真实笔屏/窗口/系统集成无法在 CI 验证。
> 逐项在本机执行并记录(通过 / 失败 + 现象)。全部通过 = S8 完成。
>
> 前置:cargo build(debug 或 scripts/build-dmg.sh 产出 Release)。建议先
> GLASPEN2_DB_PATH=/tmp/glaspen2-s8.db 用临时库,避免污染真实画册。

## A. 启动 / 窗口 / 菜单
1. 冷启动:覆盖层全屏透明、无白底;菜单栏出现马克笔状态图标;点击菜单全部项可见且中英文文案完整。
2. 菜单动作:保存(仅涂鸦/带背景)、清屏、新建页、上一页/下一页、语言切换(文案即时刷新)、设置面板打开/关闭、退出(无残留进程)。
3. 设置窗口关闭后 activation policy 回到 accessory(无 Dock 图标残留)。

## B. 书写 / 渲染
4. 笔落笔/拖动/抬笔:笔迹连续无断裂、无重影;压力变宽生效;橡皮尾切换即擦。
5. 颜色/粗细菜单切换(含书写中切换 -> 抬笔后应用暂存值);描边/软阴影开关生效。
6. 快速连笔 + 4K/Retina:无可感知延迟;GLASPEN2_PERF_LOG=1 时日志有 drawrect/模型器打点。
7. 无限画布平移/缩放(触控板/快捷键/Control-Option 拖动)、居中内容、HOME 回原点。
8. 局部重绘:大画布连续书写时无残影/漏画(脏区路径)。

## C. 翻页 / 时光隧道 / 飘渺
9. Option-Cmd Up/Down 整页翻页:系统窗口动效正常;GLASPEN2_FLIP_EFFECT=1 时隧道动画 120Hz 流畅、卡片顺序/玻璃层次正确、结束回位。
10. 飘渺模式(Control-Cmd-X):悬停/落笔显示、离开隐藏;翻页/镜头 peek 1 秒;玻璃跟随联动。
11. 缩略图条布局正确、当前页高亮、点击跳转。

## D. 输入 / 热键 / 录制
12. event tap:笔、鼠标、键盘、滚轮全部按预期路由;点菜单栏 5 秒内 tap 自动恢复;GLASPEN2_VIRTUAL_PEN=1 合成笔迹正常且不移动真实光标。
13. 可配置快捷键:录制/清空/恢复默认生效,冲突/保留组合提示正确;设置面板按钮触发同一动作。
14. GIF 录制(Control-Cmd-R):录制/结束/剪贴板可粘贴;聊天集成开时 Control-Cmd-2 草稿、Control-Cmd-3 直发走 mock/真实后端(静默降级不阻断涂鸦)。

## E. 系统集成 / 多屏
15. 磨砂玻璃开关/浓度/跟随;透明面板(设置窗口透明窟窿)。
16. 反色突出(macOS 12.3+):背景反相墨迹正确、帧率切换(10/30/60/100)、关闭恢复;12.0–12.2 上功能自动禁用不崩溃。
17. 带背景保存:12.3–13 走 CGWindowList 回退、14+ 走 SCScreenshotManager;Display P3 颜色正确、自家窗口不出现在截图。
18. 多显示器:覆盖层跟随当前屏、切换显示器后几何/页视图正确(防抖后不产生瞬态页);睡眠唤醒后正常。
19. 单实例锁、开机自启、更新检查。
