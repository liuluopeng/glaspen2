# 玻璃隧道翻页：现状与问题示意

> 这两张图是**离屏模拟**（按 `src/macos/swift/run_glue.swift` 的 `tunnel_place` /
> `tunnel_draw_card` 参数 1:1 重画，卡片内容用示意笔迹），不是屏幕截图。
> 用途是排查几何/透明度问题，不代表最终视觉。

## 现状（`current.png`，动画中点）

- 所有卡片**同心**、只按 `pow(0.92, zc)` 等比缩小；每层只小 8%，实际同屏
  只有 3–4 张，看起来像"缩放叠框"，不像纵深。
- 卡片快照**只有笔迹**，没有页面表面；玻璃面只有 8% 灰。于是后面几页的
  笔迹全部透出来，叠成一片。
- 侧面是两块纯色平行四边形，阴影是两条硬边矩形；没有圆角、渐变、
  Fresnel 高光/软阴影。
- 背景实际是**全透明**（代码注释写的是"深色磨砂玻璃"）。

## 已实现的方向（`proposed.png`，p=0.35 离屏模拟）

- 真透视（`1/(1+kz)`）+ 轻微上移，让层与层有可读的间距；
- 圆角、面渐变、侧面渐变、顶部高光、软阴影；
- 磨砂玻璃面（基准 0.84）负责**遮挡**后页，后层先画到 1/3 缓冲再放大
  做廉价模糊，避免两页笔迹叠成双重曝光；
- 外围透明（不铺全屏底色）+ 快速深度雾，远处页面只留轮廓；
- 落定帧与真实页完全对齐（commit `693b44e`），目标页从 0 淡入。

## 厚度/纯净度（`thickness.png`，单卡示意）

- **直角玻璃**：前脸矩形，无圆角；
- **侧视图厚度**：只有上侧和右侧挤出 1.8% 卡宽，形成清晰的玻璃截面；
- 去掉蓝色滤镜：中性明度渐变（顶部受光、右侧背光）；
- 背侧顶/右棱线 + 前脸顶/右交界线，用来在透视里区分前后玻璃片；
- `GLASPEN2_FLIP_THICK` 调厚度（0.002–0.10），
  `GLASPEN2_FLIP_GLASS` 调面不透明度（0.70 更通透，0.90 更遮挡）。
