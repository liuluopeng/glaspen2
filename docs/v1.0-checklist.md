# V1.0 退出标准（提案）

> 起草：2026-11-19。仓库此前没有书面的 1.0 定义，本文件把它写下来，
> 供项目所有者确认/修改。与 [release-checklist.md](./release-checklist.md)
> 互补：后者管「每次发版逐项打勾」，本文件管「什么时候可以打 v1.0.0」。

## 1.0 的含义

功能面已经完整（活页本 / 无限画布 / 导出 / GIF / 更新 / Windows 覆盖层）。
1.0 的承诺是三件事：

1. **数据不丢**：升级、异常退出、磁盘异常下，笔迹与设置可恢复；
2. **双平台可用**：macOS 与 Windows 都经过真机验证，而不是「能编译」；
3. **可分发**：用户从 Release 下载后能正常打开（签名/公证，或明确说明绕过方式）。

## 退出标准（全部满足才可打 v1.0.0）

### A. 质量门

- [ ] `sh scripts/lint.sh` 全绿（fmt / clippy / 测试 / flutter analyze / flutter test）
- [ ] CI 的 `fmt`、`clippy-test` 在 main 上连续绿（当前本地 main 领先 origin/main，
      这批提交尚未经过 CI）
- [ ] `windows-check` 从 `continue-on-error` 转为正式门
- [ ] coverage job 至少完整跑通一次并记录基线

### B. 数据

- [ ] 用 0.5.x 的真实库升级到本版，笔迹 / 页序 / 设置完整
- [ ] 迁移前备份 `glaspen2.db.before-vN` 已生成
- [ ] 磁盘满 / 只读目录下不崩溃、有可读错误提示
- [ ] 1.0 后的 schema 承诺：只增不删，变更必须带迁移 + 备份（`user_version` 已就位）

### C. 平台真机

- [ ] macOS 12+：冷启动 / 权限引导 / 翻页 / GIF / PDF / 自动更新 /
      睡眠唤醒 / 双屏热插拔 / 4K 缩放屏
- [ ] Windows 10/11 x64：压感 / 笔键 / 覆盖层不挡鼠标 / 面板各 tab /
      安装 → 卸载 → 重装 → 升级
- [ ] 连续书写 30 分钟，内存无持续增长

### D. 分发

- [ ] macOS：Developer ID 签名 + 公证（`GLASPEN2_DEVELOPER_ID` /
      `GLASPEN2_NOTARY_PROFILE`），或明确决定不公证并在 release notes 写明绕过方式
- [ ] Windows：安装器签名，或 release notes 写明 SmartScreen 提示
- [ ] DMG / setup.exe 的 sha256 写进 release notes
- [ ] 干净机器（未装过）安装验证

### E. 文档与流程

- [ ] README 中英文同步（平台 / 快捷键 / 隐私）
- [ ] CHANGELOG 有 `1.0.0` 段落，日期与 tag 一致
- [ ] release notes 写明：平台支持、已知限制、数据兼容性、回滚方式
- [ ] tag 与 push 经项目所有者确认后执行（默认只提交到本地）

## 两条路径

- **快路径**：0.6.0 质量门全绿后，直接改版本号为 1.0.0 发布。
  代码距离 ≈ 0，主要补 D / E 两项与一次真机冒烟（约 2–3 天）。
- **稳路径（推荐）**：先发 0.6.0，观察 2–4 周真实使用，确认没有 P0/P1
  数据问题后再打 1.0.0。日历时间约 3–6 周，其中编码量很小，
  主要成本是 Windows 真机、签名证书与 soak 时间。

> 1.0 之后建议冻结数据库 schema 与对外协议字段号（proto 已有
> 「字段号永不复用」规则，`user_version` 迁移机制已就位）。
